A real-time AI chatbot that lets you converse with Nikola Tesla. Built with FastAPI and WebSockets, Tesla responds in character using Google Text-to-Speech voice synthesis. Supports both text and voice input — with OpenAI GPT-3.5 for intelligent in-character responses.
